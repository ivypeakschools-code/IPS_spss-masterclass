1. Understanding Research Data

Your facilitator says Welcome! Before we ever open SPSS, we need to agree on what "data" actually is, and how a proper research dataset is put together. Everything else in this course builds on this one idea.

LEARN — Data are recorded observations, measurements, responses or classifications. On its own, raw data doesn't tell you much. A scattered list of 50 students' raw test scores is just data — it only becomes evidence once you organise, check, analyse and interpret it.

SEE — Throughout this course we will build one real research project together: the Student Academic Achievement Study, an investigation into how study habits relate to performance in Chemistry.

2. Variables and Scales of Measurement

Your facilitator says This is the single most important lesson in the whole course. Get measurement scales wrong, and every statistic you compute afterwards will be meaningless — no matter how correctly SPSS calculates it.

LEARN — A variable is any characteristic that can take different values. Measurement is the rule you use to assign numbers or categories to it.

ScaleMeaningExample (our study)
NominalCategories with no orderGender, School Type
OrdinalOrdered categories; gaps not assumed equalSatisfaction (1–5)
IntervalEqual intervals; zero is not "nothing"Temperature °C
RatioEqual intervals and a true zeroAge, Study Hours, Chemistry Score
SPSS simplification: in Variable View, interval and ratio variables are usually represented together as Scale.
Important — the coding trap: when we write 1 = Male, 2 = Female, the numbers 1 and 2 are labels, not quantities. Female is not "more" than Male. Coding a category with a number never makes it Scale.

3. Getting to Know SPSS

Your facilitator says SPSS looks intimidating the first time you open it. It really isn't — it's just a data file, a dictionary describing that data, a place to run procedures, and a place to read results.

LEARN — SPSS is built around a data file, variable metadata, procedures and output, arranged behind a menu bar:

File · Edit · View · Data · Transform · Analyze · Graphs · Utilities · Extensions · Window · Help
Data ViewCases × variables
Variable ViewMetadata
Output ViewerResults
SyntaxReproducible commands

SEE — Data View is the research data matrix in software form. Variable View is the data dictionary: name, type, label, value labels, missing values and measurement level.

Golden rule: do not rush to analysis. First make sure the variables and their coding correctly represent the research design.

Import checklist

  1. First row contains variable names.
  2. Each subsequent row represents one case.
  3. A column contains exactly one variable.
  4. No merged decorative title cells or totals rows.
  5. Inspect types, labels and missing data after import.
